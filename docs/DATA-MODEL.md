# EventAT — DATA MODEL (PostgreSQL 17, Drizzle)

The relational model behind `SPEC.md`. Rules (state transitions, money maths) live in SPEC; this document defines storage.
Drizzle files: one per module in `db/schema/` (`auth.ts`, `system.ts` exist; add `reference.ts`, `profiles.ts`, `partners.ts`, `services.ts`, `availability.ts`, `requests.ts`, `bookings.ts`, `money.ts`, `payouts.ts`, `disputes.ts`, `messaging.ts`, `reviews.ts`, `saved.ts`, `team.ts`, `invoices.ts`, `media.ts`).

## 0. Conventions

| Topic | Rule |
|---|---|
| Extensions | `citext` (emails), `pgcrypto` (`gen_random_uuid()`), `btree_gist` (range exclusion on availability blocks) |
| Primary keys | `user.id` and the other Better Auth tables use **text** ids generated by Better Auth. Every other table: `id uuid primary key default gen_random_uuid()` unless stated. FKs to `user` are `text`. |
| Naming | snake_case tables (singular) and columns. Enum types snake_case; enum values snake_case English. Bulgarian display labels live in `lib/labels.ts` (one map per enum, exact strings below). |
| Money | `integer` euro **cents** (`*_cents`), never floats; sums and ledger aggregates `bigint`. `*_bp` = basis points (1000 = 10 %). |
| Time | Instants `timestamptz`; event dates `date`; wall-clock times `time` (Sofia, no zone). Never store a Sofia date as a timestamp. |
| Standard columns | Mutable tables carry `created_at timestamptz not null default now()` and `updated_at timestamptz not null default now()` (updated by the domain layer). Listed as **`created_at`, `updated_at`** below. |
| Deletes | Business records are never hard-deleted: status columns or `deleted_at`. Cascade only on pure child rows (attachments, link tables). |
| Snapshots | Fields copied from a source at a moment (policy, prices, addresses, contact phone) are marked **snapshot** and never updated from the source. |
| Search text | Lower-case generated `text` columns for the stem matcher (SPEC §13.3), plus `pg_trgm` GIN indexes where marked. |
